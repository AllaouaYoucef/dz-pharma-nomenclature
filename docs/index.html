Nomenclature Nationale des Médicaments — Algérie

L'intégralité de la nomenclature nationale des produits pharmaceutiques à usage de la médecine humaine, exposée en JSON statique. Aucune clé d'API, aucune limite d'appel, CORS ouvert — servi par GitHub Pages.

Exemples

JavaScript

const BASE = location.origin + location.pathname.replace(/\/$/, '');

// autocomplétion à partir de l'index compact
const index = await (await fetch(`${BASE}/v1/medications.min.json`)).json();
const hits = index.filter(m => m.s.includes('paracetamol')).slice(0, 20);

// fiche complète
const fiche = await (await fetch(`${BASE}/v1/medications/${hits[0].i}.json`)).json();

C# / .NET

var http = new HttpClient { BaseAddress = new Uri(BASE + "/v1/") };
var all  = await http.GetFromJsonAsync<List<Medication>>("medications.json");
var one  = await http.GetFromJsonAsync<Medication>($"medications/{id}.json");

curl

curl -s BASE/v1/meta.json | jq .counts
curl -s BASE/v1/dci/paracetamol.json | jq '.medications[].brandName'

Avertissement

Données publiques issues du Ministère de l'Industrie Pharmaceutique, republiées à titre de référence. L'inscription à la nomenclature n'implique ni une commercialisation effective, ni une disponibilité en officine. Ce jeu de données ne contient ni posologie, ni contre-indication, ni interaction, et ne remplace pas le Résumé des Caractéristiques du Produit. Il ne constitue pas un avis médical.

Source : Nomenclature Nationale des Produits Pharmaceutiques à usage de la médecine humaine — Direction de la Pharmaco-économie, des Activités Pharmaceutiques et de la Régulation.
Code source, script de génération et signalement d'erreurs : github.com/AllaouaYoucef/dz-pharma-nomenclature.
